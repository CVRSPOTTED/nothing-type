# Приватность Nothing Type

Nothing Type обрабатывает нажатия локально и передаёт символы активному редактору
через Android InputConnection. Переписка не записывается в файлы, логи, настройки
или историю. Нет SDK аналитики, рекламы, аккаунтов, фонового сервера и разрешения
`INTERNET`. Автоматическое резервное копирование данных приложения выключено.

Подсказки и автокоррекция используют текущее набираемое слово в памяти и встроенный
словарь RU/EN. Автоисправление запрашивается флагом AUTO_CORRECT редактора и
выключается отдельно в настройках. В памяти временно хранится одно исходное
исправленное слово для отмены через Backspace. Автоматического обучения на вводе, истории слов
и удалённого API нет. В паролях, email/URL, полях без подсказок, с собственным
автодополнением и редакторах с запретом персонализации дополнения отключены.

**Голосовой ввод:** по нажатию «Голос» Nothing Type использует Android SpeechRecognizer
и запрашивает разрешение RECORD_AUDIO. Приложение не записывает аудиофайлы.
Если доступен системный on-device распознаватель (Android 12+), выбирается он.
При отсутствии локального движка или ошибке его запуска либо поддержки языка
аудио может обрабатывать настроенная системная служба: она может использовать
сеть и собственную политику конфиденциальности. Результат вставляется только в
тот же активный редактор. Закрытие клавиатуры, смена поля или начало ручного
набора отменяют прослушивание. В полях паролей голосовая кнопка скрыта.
Проверка ввода в приложении открывает обычное текстовое поле с выбранной
системной клавиатурой. Для Nothing Type действуют те же правила диктовки.
При включённом свечении уровень звука от SpeechRecognizer управляет анимацией
пятен. Уровни не сохраняются.

SharedPreferences хранит параметры оформления, положения, шрифта, языка и
способа его переключения, быстрого ввода, подсказок, автокоррекции, свечения,
тактильного отклика и звука. Импортированный пользователем Ndot-файл хранится
в приватной папке приложения. Эти данные не содержат набираемых слов.

Системный буфер обмена читается только при нажатии «Вставить». Копии и история
не сохраняются. В полях паролей и редакторах с запретом персонализированного
обучения кнопки вставки и эмодзи скрываются. Само обучение не реализовано.

Текст проверочного поля существует в памяти приложения и стандартном состоянии
элемента ввода Android. Собственная история проверочных текстов отсутствует.

Эта политика касается Nothing Type, а не приложений, в которые пользователь вводит
текст, и не поведения операционной системы.

В разделе «Мои слова» можно явно сохранить до 500 слов. Они хранятся в закрытых настройках приложения, используются только локально и удаляются пользователем в этом же разделе. Приложение не добавляет слова из набора самостоятельно.

В режиме «Голосовой ввод только без сети» используется только on-device распознаватель Android; переход к обычной системной службе отключён. Предварительная фраза отображается только на клавиатуре и не вставляется в редактор до финального результата.
