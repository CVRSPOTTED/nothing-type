# Исследовательский декодер свайпа

`SwipeDecoder.decode(trace, dictionary, limit)` принимает последовательность ближайших клавиш и словарь. Он сворачивает повторы соседних букв, ранжирует слова по расстоянию Левенштейна и отбрасывает далёкие совпадения. Для `hhheelllo` первым результатом будет `hello`, если слово есть в словаре.

Модуль работает на JVM. Сбор траектории пальца и интеграция с IME остаются отдельными этапами. Запуск тестов из корня проекта — `gradlew :swipe-research:test`.
