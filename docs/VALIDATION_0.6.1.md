# Проверка 0.6.1

9 ноября 2026. Application ID: dev.nothingtype.keyboard.
Название: Nothing Type. versionCode 10; minSdk 26, targetSdk 36.

- В рабочем Android-коде нет прежнего package ID и shim-компонента.
- Тесты подтверждают системное имя, launcher и защищённую BIND_INPUT_METHOD службу.
- 80 тестов приложения и 2 теста swipe-research прошли; Android Lint: 0 замечаний.
- Собраны debug, androidTest и unsigned release APK. aapt подтвердил новый package ID.
- Новый пакет установлен на отдельный эмулятор Android API 37. Включение IME,
  ввод, редакторы, скрытие, restart и переход в настройки прошли.
- Итоговый прогон: 1050 нажатий, точное совпадение текста и порядка.
  1000 асинхронных нажатий: 33365 мс; P50 доставки события: 37 мс, P95: 46 мс.
  Это времена автоматизации, а не аппаратная задержка экрана.
- Для повторяемости стенд ожидает UI idle перед чтением координат и создаёт
  новый WebView-редактор для каждого прогона.

Нужна повторная подпись 0.6.1 существующим ключом владельца через Android Studio.

Пароли ключа в проекте не сохраняются.

Новый ID означает отдельное приложение для Android. После установки включите
и выберите новый IME. Старые настройки и импортированный шрифт автоматически
не переносятся. Предыдущее приложение можно удалить после проверки нового.

Остальные выпускные ограничения из VALIDATION_0.6.0.md сохраняются: физические
устройства, микрофон, TalkBack, удалённая CI-матрица и проверка F-Droid в Linux.
