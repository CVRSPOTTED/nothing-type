# Android-аудит Nothing Type

Дата проверки — 7 ноября 2026 года. Объект — приложение и IME 0.5.0.
Это проверка исходников, автоматических тестов и доступного эмулятора.
Подтверждение полного соответствия требует завершения перечисленных ручных
проверок и требований выбранного канала публикации.

Основа проверки — руководство по IME и общие рекомендации качества Android.
[Создание IME](https://developer.android.com/develop/ui/views/touch-and-input/creating-input-method), [Core app quality](https://developer.android.com/docs/quality-guidelines/core-app-quality)

Для TYPE_NULL Android предусматривает ограниченный режим событий клавиатуры.
Для обычных редакторов сохранён ввод через InputConnection; пользовательские
команды редактора передаются с его actionId. [InputType](https://developer.android.com/reference/android/text/InputType#TYPE_NULL), [EditorInfo](https://developer.android.com/reference/android/view/inputmethod/EditorInfo#actionId), [события IME](https://developer.android.com/reference/android/inputmethodservice/InputMethodService#sendDownUpKeyEvents(int))

Рекомендации доступности включают цель касания 48 × 48 dp и контраст текста
4,5 к 1 для обычного мелкого текста. Полноразмерная буквенная раскладка на узком
телефоне даёт меньшую ширину отдельных ячеек; заполнение промежутков эту ширину
до 48 dp не увеличивает. Этот пункт остаётся ограничением, которое нужно
проверять с TalkBack, Switch Access и альтернативной раскладкой доступности.
[Рекомендации Android](https://developer.android.com/guide/topics/ui/accessibility/apps)

Проверки, которые закрывают готовность к публичному стабильному выпуску

- Ручной TalkBack и Switch Access, включая выбор языка, дополнительные символы,
  действия курсора, голос и каталог эмодзи.
- Все настройки шрифтов 100/160/200%, крупный системный размер экрана,
  узкий телефон, планшет, поворот и разделённый экран.
- Удаление составных эмодзи, модификаторов и объединённых графем. Сейчас удаление
  вне композиции выполняется по Unicode code point и может разобрать эмодзи на части.
- Реальные Nothing OS и ещё один производитель; заметки, браузер, мессенджер,
  менеджер паролей и терминал. Для TYPE_NULL отдельно проверить Unicode.
- Измерение задержки касание–символ, доли потерянных/неверных касаний, FPS,
  памяти и энергопотребления. Прохождение функциональных тестов не заменяет эти измерения.
- Настоящий микрофон, отсутствие разрешения, отключение доступа к микрофону,
  смена редактора во время диктовки, сетевые и языковые ошибки.
- Проверки навигационных кнопок и жеста Back, safe insets, возврата после
  блокировки и переходов между приложениями на нескольких версиях Android.
- Подпись ключом владельца, проверка обновления с тем же сертификатом,
  заполнение карточки и требований выбранного магазина.

Для новых приложений и обновлений Google Play на дату проверки требуется
target API 36. Проект переведён на этот уровень; совместимость поведения
Android 16 требует отдельной проверки, в том числе edge-to-edge и Back.
[Требование Play](https://support.google.com/googleplay/android-developer/answer/11926878?hl=en), [изменения Android 16](https://developer.android.com/about/versions/16/behavior-changes-16)
