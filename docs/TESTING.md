# Ручная проверка на Android

## Регрессия 0.3.0

- [ ] Сравнить мгновенный и обычный режимы при одинаковых раскладке и редакторе.
      Удержание буквы в быстром режиме должно вставить один символ, без дубля при отпускании.
- [ ] Набрать `прив`, выбрать `привет`; проверить `hel` → `hello`, Shift, Caps Lock,
      Backspace, пробел и знаки пунктуации. Выделение или перемещение курсора
      не должно заменять предыдущее слово при выборе следующей подсказки.
- [ ] Пароль, email, URL и поля NO_SUGGESTIONS: нет текстовых кандидатов.
- [ ] Значок меню и удержание ?123 открывают быстрые настройки; повторное нажатие значка возвращает набор.
- [ ] Проверить тему, фон, скорость, подсказки, одноручный режим и подъём из меню.
- [ ] Голос: первый запрос разрешения, отказ, повторное разрешение в настройках,
      начало, остановка, текстовый результат, отсутствие службы или языкового пакета.
- [ ] Во время диктовки скрыть IME, перейти в другое поле или начать ручной ввод:
      поздний результат не должен попасть в новое поле. Пароли — без голосовой кнопки.
- [ ] Сравнить живой фон и статичный режим; после скрытия IME анимация не работает.

## Базовые сценарии

Эти сценарии нужно выполнить на устройстве / эмуляторе. Наличие пункта в списке
не означает, что он уже пройден. Рекомендуемая матрица: API 26 и API 35, портрет
и альбомная ориентация, жестовая и трёхкнопочная навигация.

- [ ] Установка APK; запуск экрана настройки без ошибок.
- [ ] Включение в системном списке, выбор Nothing Type, актуальный статус после возврата.
- [ ] Ввод `Hello, мир! ёж съел яблоко` в заметках и строке поиска.
- [ ] Удержание пробела открывает выбор English/Русский без вставки пробела. Короткое нажатие вставляет один пробел; Shift сбрасывается после буквы; удержание Shift включает Caps Lock.
- [ ] Удержание ?123 открывает быстрые настройки; из них доступен выбор системной клавиатуры.
- [ ] Переключение символов и эмодзи; возврат ABC; пробел и Enter.
- [ ] Backspace удаляет букву, отдельный эмодзи и выделенный фрагмент.
- [ ] Стрелки перемещают курсор без вставки символов.
- [ ] Кнопка «Вставить» вставляет текущий текст; пустой буфер не вызывает падения.
- [ ] В полях textPassword, webPassword, visiblePassword и numberPassword скрыты
      эмодзи и вставка. При переходе обратно в обычное поле они появляются.
- [ ] Для поля с IME_FLAG_NO_PERSONALIZED_LEARNING также скрыты эти инструменты.
- [ ] Поля number/phone открывают соответствующие раскладки.
- [ ] Поиск, Далее, Готово, Отправить вызывают действие редактора; multiline — перенос.
- [ ] Все три темы, цифровой ряд, высота и радиус отражаются в preview и IME.
- [ ] Настройки сохраняются после закрытия приложения и перезапуска процесса.
- [ ] В альбомной ориентации редактор остаётся видимым, клавиатура не полноэкранная.
- [ ] Проверка отступов системных панелей на API 35.
- [ ] TalkBack произносит назначения кнопок; интерфейс доступен с крупным шрифтом.
- [ ] В авиарежиме обычный набор и подсказки работают без изменений. Диктовка
      зависит от наличия локальной службы и языкового пакета.

Известные ограничения: ряд русских букв тесный на узких экранах; некоторые
клавиши меньше рекомендуемой touch target ширины 48 dp. Стрелки и editor action
зависят от корректной реализации InputConnection целевым приложением. Не все
редакторы одинаково поддерживают удаление Unicode code points. Составные эмодзи
удаляются по частям; ограничений signed/decimal в числовой раскладке пока нет.

## 0.5.0 на Android

На тестовом телефоне или эмуляторе без активной работы в других приложениях:

```powershell
.\gradlew.bat assembleDebug assembleDebugAndroidTest
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb install -r -t app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb shell am instrument -w dev.nothingtype.testing/dev.nothingtype.testing.EditorSmokeInstrumentation
```

Прогон переключает системную клавиатуру на Nothing Type, проверяет обычное, парольное и десятичное поле, скрытие и повторное открытие IME и ввод в WebView второго приложения. В конце возвращает прежнюю клавиатуру.

- [ ] TalkBack объявляет символ, действие Shift, выбор языка на пробеле, удаление и команды панели. Двойное касание вводит ровно один символ. Для курсора доступны действия TalkBack на пробеле.
- [ ] Удержание точки открывает варианты без ввода точки. Свайп по пробелу двигает курсор без вставки пробела. Удержание без движения открывает выбор языка.
- [ ] Масштаб шрифта 100%, 160%, 200%. Проверить видимость букв, пробела, подсказок и настроек в обеих ориентациях.
- [ ] Планшет от 600 dp. Проверить высоту клавиш, портретную и альбомную ориентацию, режимы ширины и навигационные отступы.
- [ ] Перейти между заметками, браузером и менеджером паролей. В чувствительных полях не появляются подсказки и голосовой ввод.
