# Проверка Nothing Type

## Автоматически

JDK 17, Android SDK 36 и Build Tools 36.0.0:

```powershell
.\gradlew.bat testDebugUnitTest :swipe-research:test lintDebug assembleDebug assembleDebugAndroidTest assembleRelease
```

Тесты проверяют ввод, мультитач, редакторы без композиции, удаление графем,
T9, ручной словарь, выбор языка, масштаб 200%, восстановление настроек и
диктовку с отменой поздних результатов. Отдельные тесты Unicode работают на
API 26 и 34. Эти проверки не заменяют TalkBack и физическое устройство.

## Установленный IME

Используйте отдельный эмулятор или тестовый телефон. Укажите его serial вместо SERIAL:

```powershell
adb -s SERIAL install -r app/build/outputs/apk/debug/app-debug.apk
adb -s SERIAL install -r -t app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb -s SERIAL shell am instrument -w -r dev.nothingtype.testing/dev.nothingtype.testing.EditorSmokeInstrumentation
```

Успех: `INSTRUMENTATION_CODE: -1`. Прогон проверяет нативные редакторы,
пароль, числа, WebView отдельного приложения, повторный запуск IME, T9,
касания краёв и перекрывающиеся касания. После него возвращается прежний IME.
Настройки и введённые данные тестового редактора не являются личными данными пользователя.

Нагрузка: 1000 быстрых касаний с проверкой порядка и отсутствия пропусков,
затем 50 отдельных замеров. В результате есть `verified_taps`, `burst_1000_ms`,
`dispatch_to_editor_p50_ms` и `dispatch_to_editor_p95_ms`.
Эти времена включают автоматизацию и доставку событий: это не аппаратная
задержка экрана и не сравнение с Gboard. Сравнивайте прогоны на одном устройстве
при одинаковых температуре, настройках и нагрузке. Текст в журнал не выводится.

В CI настроены эмуляторы API 26, 30 и 36. Зелёный локальный тест не означает,
что удалённая матрица уже прошла.

## Ручной выпускной список

- [ ] Nothing OS и ещё один производитель: заметки, браузер, мессенджер, менеджер паролей.
- [ ] TalkBack: буква, Shift/Caps, Backspace, подсказка, язык, удержание, голос, эмодзи.
- [ ] Switch Access: доступ ко всем действиям без жеста.
- [ ] Шрифт 100/160/200%, узкий экран, планшет, обе ориентации, разделённый экран.
- [ ] Жестовая и трёхкнопочная навигация; Back; блокировка и возврат.
- [ ] Быстрый набор двумя пальцами с включённым/выключенным свечением и T9.
- [ ] Оба варианта RU: отдельные Ё/Ъ и удержание Е/Ь. Заглавные альтернативы.
- [ ] Свой словарь: добавить, удалить, перезапустить; пароли/email/URL без подсказок.
- [ ] Микрофон: первый запрос, отказ, постоянный отказ, выключенный доступ в системе.
- [ ] Диктовка: предварительный текст не вставляется, финальный — один раз.
- [ ] Во время диктовки сменить поле, приложение, язык и начать ручной ввод.
- [ ] Режим без сети: нет перехода к системному сетевому распознаванию.
- [ ] Семейные эмодзи, флаги, оттенки кожи и комбинируемые буквы удаляются целиком.
- [ ] Обновление APK с тем же release-сертификатом сохраняет настройки.

Для измерения настоящей задержки касание–символ, FPS, памяти и энергии нужен
физический телефон и профилирование. Не записывайте пользовательскую переписку.
