# Разбор идеи

Дата изучения: 5 ноября 2026 года.

Источник: [публичная страница Typebase](https://play.google.com/store/apps/details?id=com.typebase.app).
Это анализ описания магазина, а не установленного приложения: APK оригинала не
запускался, поведение и заявления о производительности не проверялись. Скриншоты
магазина не удалось загрузить через инструмент просмотра. Визуальное оформление
Nothing Type разработано самостоятельно.

Typebase позиционируется как настраиваемая Android-клавиатура. В описании указаны
темы, цвета, шрифты, раскладки, размер и скругление клавиш, эмодзи, жесты, буфер,
цифровой ряд, звук и вибрация. В заметках версии 1.5.0 упоминаются автокоррекция,
Zero Latency Mode и статистика движка. Это заявления разработчика магазина.

| Направление | Nothing Type MVP |
|---|---|
| Системный ввод | Нативный InputMethodService, а не макет клавиатуры |
| Внешний вид | Три палитры, высота, скругление, интерактивный preview |
| Языки | Английский и русский |
| Дополнительный ввод | Символы, эмодзи, цифровая и телефонная раскладки |
| Редактирование | Удаление, курсор, явная вставка из буфера |
| Приватность | Без INTERNET; настройки хранятся локально |
| Автокоррекция / свайп | За пределами MVP; отдельная исследовательская задача |
| Статистика / Zero Latency | Не реализованы; измерений производительности нет |

Архитектура опирается на [официальное руководство Android по IME](https://developer.android.com/develop/ui/views/touch-and-input/creating-input-method).
Для воспроизводимой сборки выбраны AGP 8.9.2, Gradle 8.11.1, Kotlin 2.1.20,
JDK 17, SDK 35; [матрица совместимости AGP](https://developer.android.com/build/releases/agp-8-9-0-release-notes).

Цель пет-проекта — показать работу с платформенным API, отделение логики состояния
от UI, обработку разных редакторов, тесты и CI. Первая версия намеренно обходится
без ML и сервера, чтобы оставаться понятной и расширяемой.
