# Nothing Type и Gboard

Проверено 7 ноября 2026 года. Состояние Nothing Type определено по исходникам
ветки разработки 0.5.0. Возможности Gboard сопоставлены с официальной справкой
для Android. Доступность отдельных функций Gboard зависит от языка, устройства
и региона. Наличие функции и качество её распознавания оцениваются отдельно.

| Возможность | Nothing Type | Следующий этап |
| --- | --- | --- |
| Буквенные раскладки и смена языка | RU/EN, выбор удержанием пробела либо отдельной кнопкой | Дополнительные языки и варианты раскладок |
| Shift и Caps Lock | Однократный Shift и удержание для Caps Lock | Двойное нажатие Shift, как в справке Gboard |
| Дополнительные символы | Удержание части букв, запятой и точки; две символьные страницы | Расширение диакритики и подсказки символов на клавишах |
| Курсор на пробеле | Есть горизонтальный жест и действия доступности | Проверка жестов на нескольких физических устройствах |
| Рукописный ввод | Отсутствует | Отдельный модуль распознавания |
| GIF | Отсутствуют | Провайдер, лицензии и согласованная политика данных |

Сравнение раскладок, Caps Lock, удержаний, жеста курсора, GIF и рукописного ввода
основано на пользовательской справке. [Использование Gboard](https://support.google.com/gboard/answer/2842292?co=GENIE.Platform%3DAndroid&hl=en)

| Возможность | Nothing Type | Следующий этап |
| --- | --- | --- |
| Дополнение слова | До трёх вариантов из компактного встроенного RU/EN-словаря | Расширить словарь с проверенной лицензией и частотами |
| Автокоррекция | Однозначные опечатки в одно изменение, возврат Backspace; учитываются флаги редактора | Более точное ранжирование и оценка ошибок на корпусе |
| Следующее слово и предложения | Отсутствуют | Контекстная локальная модель |
| Пользовательский словарь | Отсутствует | Явное добавление, удаление и очистка слов |
| Персонализация и удаление нежелательных подсказок | Обучение отсутствует | Управляемое пользователем локальное обучение |
| Проверка грамматики и переписывание | Отсутствуют | Отдельная продуктовая задача после базового ввода |

Справка Gboard описывает выбор и удаление подсказок, пользовательский словарь,
возврат автоисправления и некоторые контекстные возможности. Расширенные
инструменты письма имеют отдельные ограничения доступности. [Подсказки и исправления](https://support.google.com/gboard/answer/7068415?hl=en), [инструменты письма](https://support.google.com/gboard/answer/16515540?hl=en)

| Возможность | Nothing Type | Следующий этап |
| --- | --- | --- |
| Свайп-набор слов | Есть исследовательский модуль, к IME не подключён | Траектории, декодер, словарь, отмена и тесты ошибок |
| Буфер обмена | Вставка текущего текстового элемента по нажатию | История, закрепление, удаление и срок хранения |
| Выделение частей буфера | Отсутствует | Отдельный локальный анализ и пользовательский выбор |
| Перевод при вводе | Отсутствует | Выбор движка, лицензий и режима обработки текста |
| Базовая диктовка | Системный SpeechRecognizer, RU/EN, разрешение микрофона | Проверки реальных служб и ошибок сети/языка |
| Расширенная диктовка | Нет собственных голосовых команд, автоматической пунктуации и непрерывного редактирования | Отдельная задача; функции Gboard для Pixel не являются общим Android API |
| Реакция свечения на голос | Есть, при наличии RMS-событий службы | Проверка с реальным микрофоном и Nothing OS |

Источники для этой группы функций. [Свайп-набор](https://support.google.com/gboard/answer/2811346?hl=en), [буфер обмена](https://support.google.com/gboard/answer/10742542?hl=en), [перевод](https://support.google.com/gboard/answer/7421372?hl=en), [обычная диктовка](https://support.google.com/gboard/answer/2781851?hl=en), [расширенная диктовка](https://support.google.com/gboard/answer/11197787?hl=en)

Каталог Nothing Type содержит 3 781 эмодзи в девяти группах. Собственных поиска,
недавних эмодзи, избранного и отдельного выбора оттенка кожи пока нет. Поддержка
отрисовки конкретного эмодзи зависит также от Android и шрифтов устройства.

Специальные режимы Gboard, включая Morse, ASL-to-text и Rambler/Gemini, у нас
отсутствуют. Это отдельные направления с собственными ограничениями языка,
оборудования и обработки данных. [Morse](https://support.google.com/gboard/answer/9011881?hl=en), [ASL-to-text](https://support.google.com/gboard/answer/17468449?hl=en), [Rambler](https://support.google.com/gboard/answer/17468539?hl=en)

Приоритет следующей реализации

1. Закрыть проверки качества из Android-аудита, измерить пропуски и задержку
   на физических устройствах, исправить удаление составных эмодзи целиком.
2. Расширить и оценить RU/EN-словарь, добавить явный пользовательский словарь.
   Сравнивать точность на одном наборе текстов и касаний, с одинаковыми настройками.
3. Добавить поиск эмодзи, затем подключить исследовательский свайп-декодер.
4. Историю буфера, перевод, GIF и расширенную диктовку проектировать отдельно,
   с понятными разрешениями, хранением и удалением данных.

Функциональные отличия от Gboard служат планом развития. Требования к
публикуемой Android-клавиатуре и незакрытые проверки перечислены отдельно.
