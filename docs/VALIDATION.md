# Результаты проверки

5 ноября 2026 года, Windows x64.

- JDK: Eclipse Temurin 17.0.21.
- Android SDK Platform 35, Build Tools 35.0.0.
- Gradle 8.11.1, Android Gradle Plugin 8.9.2, Kotlin 2.1.20.
- Команда: `gradlew.bat testDebugUnitTest lintDebug assembleDebug`.
- Результат: **BUILD SUCCESSFUL**.
- Версия **0.4.2**. Прошли 37 тестов, включая измерение границ кнопок в обычном
  и быстром меню и проверку высоты букв и символов при обоих состояниях цифрового ряда.
- В Robolectric смоделированы отказ локального движка из-за отсутствия языка,
  переход на системную службу, уведомление курсора и вставка результата в поле.
  Проверка с настоящим микрофоном на Nothing OS остаётся ручной.
- UI-тесты проверяют ввод при ACTION_DOWN без повтора при ACTION_UP, смену регистра
  с сохранением экземпляров клавиш, выбор кандидата, меню и скрытие приватных инструментов.
- Тесты каталога проверяют 3 781 уникальную запись и вставку флага целиком. В EN и RU проверены ввод пробела и положение запятой и точки. Удержание удаления и остановка после отпускания проверены в обоих режимах ввода.
- Проверен выбор русского языка удержанием пробела без вставки текста и последующий ввод коротким нажатием.
- Android Lint: No issues found.
- Debug APK собран; это отладочная сборка, не подписанный production release.

Из-за кириллицы в пути рабочей папки сборка выполнена из идентичной копии
исходников во временной папке с латинским путём. SDK и кеши зависимостей не
включены в репозиторий или архив исходников.

**Не проверено для 0.4.2:** установка и запуск на устройстве/эмуляторе, визуальное
отображение, реальные InputConnection разных редакторов, TalkBack, поведение
на физических клавиатурах и OEM-версиях Android. Чек-лист — [TESTING.md](TESTING.md).
GitHub Actions подготовлен, но удалённый запуск ещё не выполнялся.

Robolectric не измеряет аппаратную задержку и не тестирует реальные микрофон,
распознаватель или FPS. Эти сценарии перечислены в ручном чек-листе.

Пользователь подтвердил установку и работу предыдущей версии 0.1.0 на своём
устройстве. Его скриншот показал наложение системных кнопок на нижний ряд;
в 0.2.0 добавлены отдельный резерв навигации и WindowInsets. Проверка исправления
на том же устройстве ещё не выполнена.
