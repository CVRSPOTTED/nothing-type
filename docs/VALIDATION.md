# Результаты проверки 0.5.0

Дата прогона — 7 ноября 2026 года.

Проверена сборка после аудита Gboard и Android. Итоговые артефакты имеют
versionCode 8, minSdk 26, compileSdk 36 и targetSdk 36. Значения подтверждены
через Android SDK aapt по собранному debug APK.

- JDK 17.0.21, Gradle 8.11.1, Android Gradle Plugin 8.9.2, Kotlin 2.1.20.
- Android SDK Platform 36 и Build Tools 36.0.0.
- Полный прогон начат с clean. После корректировки адаптивной высоты кнопок
  повторно выполнены проверки и сборка.
- Команда проверки `gradlew.bat testDebugUnitTest :swipe-research:test lintDebug assembleDebug assembleDebugAndroidTest assembleRelease`.
- Результат сборки BUILD SUCCESSFUL.
- Прошли 66 тестов приложения и 2 теста исследовательского декодера.
- Android Lint сообщает 0 замечаний в lint-results-debug.xml.
- В тестовом коде остаётся предупреждение Robolectric об устаревшем методе
  настройки фиктивной службы распознавания. Ошибок компиляции нет.

Автоматические проверки включают

- Все буквы RU/EN, регистр, Caps Lock, цифровые signed/decimal-поля.
- Все печатные ASCII-символы на буквенной и двух символьных страницах.
- Стабильную высоту страниц символов и физические позиции клавиш в RTL-системе.
- Мультитач, зоны между клавишами, смещение пальца, повтор удаления и жест курсора.
- Взаимное отключение двух способов смены языка и сохранение настройки.
- T9, подсказки, отмену исправления и ограничения редакторов.
- Пользовательский actionId/actionLabel, IME_FLAG_NO_ENTER_ACTION, TYPE_NULL.
- Сохранение набранной композиции при restartInput.
- Диктовку с резервным переходом на системную службу.
- Реакцию свечения на RMS и отсутствие реакции на обычный набор.
- Каталог из 3 781 эмодзи и вставку последовательности флага.
- Планшетную конфигурацию в Robolectric при масштабе шрифта 160%.

Инструментальный тест прошёл на Medium Phone, Android 17 / API 37.
Он проверил настоящий установленный IME, нативный редактор, парольное и
десятичное поля, WebView второго приложения, скрытие и повторное открытие,
автозаглавные, T9 и отмену, быстрые и перекрывающиеся касания, промежутки между
клавишами, смещение пальца и переход из клавиатуры в настройки.

Собраны debug APK, APK инструментального теста и неподписанный release APK.
Release-сертификат владельца в этом прогоне не использовался. Отладочный APK
подписан ключом отладочной сборки.

Рабочая папка содержит кириллицу, поэтому сборка выполнена из копии исходников
в латинском временном пути. SDK, Gradle-кеши и ключи исключены из архива исходников.

Остаются ручными проверки TalkBack/Switch Access, всех экранов при 200%,
реального микрофона и Nothing OS, физической задержки, FPS, энергопотребления
и поведения на API 26, 35 и 36. API 37 на эмуляторе не заменяет эти прогоны.
Удаление составных эмодзи целиком пока не реализовано. Условия готовности
собраны в [Android-аудите](ANDROID_QUALITY_AUDIT.md).
