# Set up Nothing Type

1. Install the signed APK from [GitHub Releases](https://github.com/CVRSPOTTED/nothing-type/releases). Android may ask you to allow installation from the app that opened the file.
2. Open Nothing Type and choose an app language if prompted. From **Enable**, tap **Enable Nothing Type**, turn it on in Android settings, then return to the app.
3. Tap **Select keyboard** and choose **Nothing Type**. Open **Settings** or **Style** and tap **Try typing**.

## Frequently asked questions

### The keyboard is enabled. Why does another keyboard appear?

Enabling Nothing Type makes it available to Android. Tap **Select keyboard** in Nothing Type and choose it to start using it.

### How do I change the typing language?

Open **Settings → Keyboard languages** and enable the layouts you use. Hold **Space** to pick a layout, or choose **Globe to the left of Space** in the language switch settings. Set the app's interface language separately under **Settings → App language**.

### How do I install or replace Ndot?

Open **Style** and tap **Ndot**. Pick an OTF, a TTF, or a ZIP containing a font. Nothing Type selects the imported font automatically. Use **Replace Ndot font** to pick a different file. The letters available in the file depend on the font.

### Why is the microphone missing or failing?

Turn on the keyboard toolbar and try dictating in a normal text field. In **Settings**, open **Set up microphone access** and allow the microphone. Dictation uses the current keyboard language. If **Offline voice input only** is enabled, Android needs an on-device speech service and a model for that language.

### Can the keyboard learn what I type?

Suggestions and autocorrect run on the device. Add words manually under **My words**. Nothing Type keeps no typing history. Android’s speech provider processes dictation according to its own settings. [Privacy policy](../PRIVACY.md)
