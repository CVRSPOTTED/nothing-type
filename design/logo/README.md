# Nothing Type logo

Approved concept: near-white circle on black, dotted SPACE capsule and red Enter.

- approved-reference.png — user-selected visual reference.
- nothing-type.svg — editable vector master for the square logo.
- Android vectors: app/src/main/res/drawable/type_mark.xml and type_mark_mono.xml.

Adaptive layers are 108dp; badge radius 32dp keeps the design inside the 66dp safe area. API33+ includes the monochrome layer; round launchers use the same adaptive artwork.

Rendered files: icon-512.png (full-square store icon), icon-round-preview.png, icon-themed-preview.png, icon-previews.png (comparison sheet). PNGs are rasterizations of the vector artwork. The approved raster remains a visual reference; Android uses vector resources.
